# Roboto

These Roboto font files are copied from the `MaterialDesignThemes`
`4.7.0-ci390` package already used by the legacy WPF project. Embedding the
same faces keeps WPF and Avalonia text metrics consistent and avoids depending
on fonts installed on the host operating system.
